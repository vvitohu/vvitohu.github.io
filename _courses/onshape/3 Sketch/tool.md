# 草圖繪製

## 草圖基礎：從 2D 到 3D 的起點

在 Onshape 中，我們在建模的步驟通常是：**草圖繪製 → 形狀建立 → 細節加工**  這三步驟來完成。

草圖並不只是線條的組合，它是設計的起點。在開始前，最重要的步驟是「選擇設計平面」——也就是決定你的圖要在哪個位置開始。無論是選擇基礎的 XY 軸平面，還是物體的某個表面，這決定了你的設計將會影響哪個部分的零件。

### 1. 開啟草圖的第一步

點擊工具欄左上角的 **「Sketch」** 圖示後，系統會要求你選擇一個 **Sketch Plane（草圖平面）**。你可以選擇：

- 預設的三個基準面（Front, Top, Right）。
- 零件上的任何一個平整表面。

### 2. 核心繪圖工具

開啟草圖後，工具列會切換為草圖專用工具，畫草圖就和畫小畫家一樣，需要甚麼工具就用甚麼，要注意的是每一條線的端點和端點都要相連。

以下是最常用的幾種工具：

- **直線 (快捷鍵 L)：** 定兩點連成一線。
- **圓形 (快捷鍵 C)：** 定圓心跟圓周上的一點。
- **矩形 (快捷鍵 G)：** 定對角兩點就能畫出框框。
- **三點定弧 (快捷鍵 A)：** 適合畫圓弧狀的線條。
- **虛線 (快捷鍵 Q)：** 這是**輔助繪圖用的**，它不會影響之後變成立體，但能幫你定位或對齊。
