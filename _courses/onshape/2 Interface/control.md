# 視角與軟體操作

## 一、視角控制

在Onshape中，我們可以透過旋轉畫面來查看模型的各個地方，而控制畫面的方式有兩種**：滑鼠及視角方塊**

### **A. 滑鼠操作**

在軟體的 3D 空間中，所有的移動都靠滑鼠完成。

- **左鍵：** 單純的「選取」物件。
- **右鍵：** 按住不放並拖曳，可以用來「**旋轉視角**」。
- **中鍵（滾輪）：**
    - **滾動：** 放大或縮小視角。
    - **按住拖曳：** 「**平移視角**」，也就是把整個畫面抓著移動。

### **B.視角方塊**

位於畫面右上角的「視角方塊」是另一種控制視角的方式，點擊它可以快速切換到不同的標準視角。

- **點擊面 (Faces)：** 點擊方塊上的 `Front`、`Top` 等，視角會垂直於該平面。
- **點擊邊線或頂角：** 快速切換到特定的斜角或等角透視視圖。
- **箭頭旋轉：** 點擊方塊旁的微調箭頭，可以將目前視角旋轉 90°。
- **下拉選單：** 方塊下方的小箭頭點開，可以選擇 **Isometric (等角視圖)** 或 **Zoom to fit (縮放至全視窗)**。

## **二、軟體操控秘訣**

熟記以下操作能讓你的建模流程更流暢：

1. **取消所有選取：** 按下鍵盤的 **空白鍵**，可以快速清除目前選中的所有物件。
2. **取消工具：** 如果選錯了工具，按下 **ESC** 鍵即可退出目前的工具模式。
3. **確認操作：** 當你在特徵面板設定好參數（如擠出高度）後，按下 **Enter** 鍵即可確認完成
