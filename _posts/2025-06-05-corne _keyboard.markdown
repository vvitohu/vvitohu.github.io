### 🚀 Corne Keyboard — 客製化分體鍵盤

這是一款專為追求高效能、極致人體工學與高度客製化玩家打造的 **4x6+3 * 2 配列分體式機械鍵盤**。結合了現代 3D 列印技術與強大的硬體擴充性，旨在提供最舒適、最直覺的輸入體驗。

本專案融合了極致的雙手人體工學與強大的硬體擴充性。每側擁有 4x6 的直列錯位按鍵佈局，能有效減少手指跨行輸入的疲勞，並搭配 3 顆大拇指特化鍵，將最常用的功能鍵交給最強壯的大拇指負責。不論是日常盲打還是複雜的快捷鍵組合，都能游刃有餘。

### 核心特色

- **人體工學黃金排列 (4x6+3)**
採用 4x6 鍵的直列或錯位佈局，搭配左右各 3 顆大拇指鍵。讓雙手自然垂放、遠離手腕代償，用最少的手指移動距離，達成最高的輸入效率。
- **多維度硬體控制：旋鈕** 
打破傳統鍵盤的限制，整合了**多功能旋鈕，**讓你的雙手無需離開鍵盤，就能掌控一切。
- **靈魂觸感，隨心所欲：茶軸 & 熱插拔設計**
全鍵支援**熱插拔（Hot-swappable）**，無需焊接即可自由更換軸體。專案目前標配微段落感的經典**茶軸**，兼顧清晰的打字反饋與舒適的按壓手感，無論辦公還是深夜寫程式都恰到好處。
- **雙模自由連線：Wireless & USB-C**
支援高速 **USB-C 有線連接**與低功耗無線藍牙模式。多裝置無縫切換，徹底解放桌面空間，告別繁雜線材。
- **極客美學：客製化 3D 列印外殼**
外殼採用精心設計的 **3D 列印結構**，在確保結構剛性的同時，提供獨特的工藝質感。開源的幾何外型設計，方便未來隨時調整傾角或升級外殼外觀。
- **最強開源心臟：ZMK 韌體支援**
基於現代無線分體鍵盤的首選開源韌體 **ZMK Firmware**。擁有極致的省電優化、極低的輸入延遲，並支援強大的鍵位映射、多層級切換以及靈活的藍牙多裝置配對管理。

#### 🛠 技術規格總覽

| **規格項目** | **詳細配置** |
| --- | --- |
| 按鍵佈局 | 4x6 + 3 大拇指鍵（每側 27 鍵，共 54 鍵分體設計） |
| 連線方式 | 藍牙無線 (Wireless) / USB-C 有線連接 |
| 軸體支援 | 全鍵熱插拔 PCB / 標配微段落茶軸 |
| 硬體擴充 | 旋鈕 (Rotary Encoder) + 多功能搖桿 (Joystick) |
| 外殼工藝 | 高精度 3D 列印人體工學外殼 |
| 韌體系統 | ZMK Firmware（支援開源自定義、多層設定） |
