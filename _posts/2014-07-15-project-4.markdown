graph TD
    %% 全域與初始化
    Start([機器人電源開機啟動]) --> InitTeensy[下位機 Teensy 4.1 啟動 FreeRTOS<br>初始化馬達驅動/編碼器/感測器]
    Start --> InitFRDM[上位機 FRDM-i.MX93 啟動 Linux/ROS<br>載入 YOLOv8-nano 模型與 LiDAR 驅動]
    InitTeensy --> CommCheck{雙板通信連線檢查<br>UART / CAN}
    InitFRDM --> CommCheck
    
    %% 定時與感測階段
    CommCheck -- 成功 --> LoopStart[進入主控定時循環]
    LoopStart --> Sensing[1. 定時與感測階段 Sensing<br>下位機高頻讀取編碼器與底層感測器<br>上位機採集 LiDAR 點雲與相機影像]
    
    %% AI影像辨識與高階運算
    Sensing --> AI_Recog[2. AI 影像辨識階段 Image Recognition<br>FRDM-i.MX93 NPU 硬體加速推論<br>即時辨識賽道、障礙物與目標孔位置]
    AI_Recog --> PathPlan[3. 高階決策與路徑規劃<br>ROS 進行多感測器資料融合<br>LiDAR 規劃最佳路徑與切換戰術邏輯]
    
    %% 決策與動作執行
    PathPlan --> TargetCheck{是否到達指定投射點?}
    TargetCheck -- 否 --> NormalMove[4. 做出動作: 生成行進指令<br>計算移動速度與轉向方向向量<br>發送控制命令至下位機]
    TargetCheck -- 是 --> BallThrow[4. 做出動作: 執行球體投射<br>根據目標孔高度120-290cm與距離<br>即時計算並輸出最佳初速與發射仰角]
    
    %% 下位機動作與安全機制
    NormalMove --> TeensyExec[下位機 FreeRTOS 任務調度<br>高頻 PID 馬達驅動控制<br>精準執行循線、轉向與定位動作]
    BallThrow --> TeensyExec
    
    TeensyExec --> SafetyCheck{下位機偵測到緊急狀況?<br>如突發障礙物 / 跌落風險}
    SafetyCheck -- 是 --> EmergencyBrake[底層防護: 緊急煞車避障<br>觸發 FreeRTOS 最高優先級任務<br>強制中斷動作並煞車]
    SafetyCheck -- 否 --> Feedback[控制閉環: 數據即時反饋<br>將編碼器與馬達狀態回傳上位機修正]
    
    Feedback --> LoopStart
    EmergencyBrake --> LoopStart
